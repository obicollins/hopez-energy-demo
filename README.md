# HOPEZ Energy — public website demonstration

A portfolio demonstration of the public HOPEZ Energy website, built by Tobey Collins with Laravel, responsive CSS and JavaScript.

## Included

The six current public brochure pages, responsive navigation, hero carousel, public imagery, and enquiry interface. The static files are rebased for GitHub Pages at /hopez-energy-demo/.

## Boundaries

This is a frontend portfolio demonstration. Form delivery is disabled. The Laravel application, staff portal, database, enquiries, environment files, application key, session tokens and other private data are excluded. Public business contact details already visible on the website remain present.

GitHub Pages: https://obicollins.github.io/hopez-energy-demo/
